Introduction

The goal of this TD is to go back over what we have seen this semester and apply it to a new dataset.

The file ai_students.csv contains 5,000 university students. For each student, we know how much they used generative AI tools (like ChatGPT) during one semester, how they used them, and how their semester went. Each row is one student. Load it with read.csv() and call it data.

Variable Description
Student_ID Student identifier
Major_Category Field of study: Arts, Business, Humanities, Medical or STEM
Year_of_Study Freshman, Sophomore, Junior, Senior or Graduate
Pre_Semester_GPA GPA before the semester (out of 4)
Weekly_GenAI_Hours Hours per week spent using generative AI (0 to 40)
Primary_Use_Case Main use of AI: Copywriting/Drafting, Debugging/Troubleshooting, Direct_Answer_Generation, Ideation or Summarizing_Reading
Prompt_Engineering_Skill How good the student is at writing prompts: Beginner, Intermediate or Advanced
Tool_Diversity Number of different AI tools used (1 to 5)
Paid_Subscription Whether the student pays for an AI subscription (True/False)
Traditional_Study_Hours Hours per week spent studying without AI
Perceived_AI_Dependency How dependent on AI the student feels (1 to 10)
Institutional_Policy Whether the student’s university allows AI (Allowed) or bans it (Banned)
Anxiety_Level_During_Exams Anxiety during exams (1 to 10)
Post_Semester_GPA GPA at the end of the semester (out of 4)
Skill_Retention_Score Score on a test measuring how much of the course content the student retained (out of 100)
Burnout_Risk_Level Risk of burnout: Low, Medium or High

Question 3: Missing values

Real data almost always have missing values. Let’s check ours.

A) How many missing values are there in each column? Use colSums(is.na(data)).

B) Is the number of missing values the same in all years of study? Run the code below to answer:

data <- data %>%
  mutate(n_missing = rowSums(is.na(pick(everything()))))   # creates a column called n_missing that computes the number of missing values per student

data %>%
  group_by(Year_of_Study) %>%
  summarise(students = n(),
            missing_values = sum(n_missing),
            missing_per_student = mean(n_missing))

For now, we’re going to take the simple route to deal with missing values: run this code to remove all of them.

data <- na.omit(data)
